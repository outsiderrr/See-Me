# 原始材料标签口径（暂行）

> **状态：暂行 v0**。2026-08-09 由用户在 W29–W31 标注实践中逐条确认，规则还不算定死，
> 后续可能调整；调整时改这个文件并在下面的修订记录里留痕。
> 适用对象：给数据湖 `原始/` 里的材料贴标签的任何 agentic AI（Claude / Codex / Trae / Kimi…）。
> 产物契约与校验见 `tools/import/raw.mjs`（check 会拦红线，但口径质量靠这份文件 + 人工确认）。

## 标注单元

标注对象是**原始材料本身**，不是整理笔记：

- flomo：每条笔记一个单元（`…md#第N条`）
- ChatGPT：每个对话文件一个单元
- Codex：每个任务轮次一个单元（`…md#任务轮次N`）
- 语音备忘录：每条录音一个单元

`source` = 相对 `原始/` 的路径 + 判别符，是幂等的锚，一个字都不能错。

## 八项已确认口径（2026-08-09）

1. **一套标签系统**。领域用减号路径（`交易-复盘-关键`），跨领域用独立标签交集。
   AI 只写**最深一级**路径，上级由程序补齐（`raw.mjs check` 直接采用 `final_tags`）。
2. **来源性质标签**：`外部材料`（课程转录/书摘/他人内容）、`AI整理`（AI 生成后被
   用户保存的文本）。这是把「用户保存的」和「用户说的」分开的关键机制。
3. **双贴规则**：AI 整理的内容若是用户本人的话/系统/结论（"按照您给出的思路"、
   "您刚才提到的内容的总结"、"记录完毕"式代笔），同时贴 `AI整理` + 表明用户原创的
   性质标签（观点/规则/复盘）；AI 自行发挥的解释、建议、框架**只贴** `AI整理`，
   绝不冒充用户观点。对话单元中被保存的 AI 实质产出构成重要内容时才贴 `AI整理`。
4. **`私密` 口径不扩**：仅限情感/家庭/资产等敏感内容；持仓、盘前计划、交易心态不算。
5. **`文案` 是内容性质**；来源性质另行判断，无法判断原创性的格言短句**不贴**
   观点/外部材料等归属类标签。
6. **发布红线**：AI 绝不添加任何 `发布-*` 标签；`可分享` 只能作为需用户确认的建议
   出现，不进标签。服务端（`/api/raw/import`）对这两类硬拒，整批打回。
7. **新标签从严**：含义稳定、可复用、不与已有标签近义重复才建，且必须声明在
   `new_tags`。单次使用的概念不建标签（先例：副业→并入交易，经济→未采纳）。
   非交易的通用思考用 `想法` 作领域桶，与性质标签 `观点` 可并存。
8. **重复条目**只在导入层判重（`duplicate_of` 互记），原始文件永不改动。

## 归属判断底线（与提炼提示词一致）

- 用户提问 ≠ 用户认同；保存在 flomo ≠ 用户原创或认领。
- AI 口吻特征（"你的这段感悟很有深度"、"好的，这是为您生成的"、emoji 小标题、
  通篇称"您"）、课程转录（"说话人1："）、书摘 → `AI整理`/`外部材料`/`课程转录`，
  除非满足双贴规则，否则不得携带 观点/规则/复盘。
- 语音转写中方括号标注的不确定段，内容不作为标签或归属依据。
- 归属枚举：用户观点 / 用户随记 / AI整理 / 课程转录 / 外部摘录 / 系统内容 / 混合 / 不确定。
- 拿不准就 `confidence: 低` + `needs_confirm: true`，交人工确认，不要猜。

## 产物与管线

```
周报/<week>/<week>-标签.json  ← 标注产物（含 units[].source/tags/final_tags/…）
        │  tools/import/raw.mjs check   （湖侧：回溯正文、拦红线、产 payload）
        ▼
raw-upload.json ── raw-upload.sh ──▶ 服务器 /api/raw/import（幂等 upsert，重传=刷新）
```

原始材料层在服务端是独立表（`raw_units`），邀请卡/公开卡的匹配只查 `note_tags`，
原始材料在结构上进不了任何分享。展示层仍由本地 AI 整理后经 `tools/import` 上传，
服务端不做整理。
