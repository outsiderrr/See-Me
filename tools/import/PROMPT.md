# Fathom 提炼提示词（正式版）

> 把这份文件整个交给你的 agentic AI（Codex / Claude / 任意有 shell 的助手）。
> 它是自足的：不需要任何本文件之外的背景知识。
> 管线里它的位置：`原始/`（素材）──本提示词──▶ `库/`（原子笔记）──`tools/import`──▶ 服务器。
> 提炼刻意不由代码调模型——契约是文件格式，零凭证依赖、零厂商锁定。
> 产物会被 `tools/import/import.mjs check` 独立校验，别指望"大概符合"能过。

## 任务

读数据湖里还没提炼过的原始素材，把**用户本人的想法**提炼成原子笔记，写进 `库/`。

- 数据湖：`~/通用空间/潜心/`
- 输入：`原始/语音备忘录/2026-Wnn/raw/*.md`（录音转写稿）和 `原始/chatgpt/2026-Wnn/raw/**/*.md`（对话记录）
- 周报（`2026-Wnn.md`，在 raw/ 外面）只是索引摘要，**不提炼**
- 输出：`库/<覆盖的最新采集周>.md`（如 `2026-W30.md`），一批只写一个文件
- **幂等**：动手前先收集已有 `库/*.md` 里所有 `source:` 行——已经出现过的素材跳过，只提炼新的

## 输入格式

**录音（voice）**：头部列表含录音日期、时长、源文件、转写方式；正文在 `## 自动转写正文`；
可选 `## 识别说明`。转写不确定处用方括号标注，如 `[结尾未完整说清。]`。

**对话（chat）**：头部列表含项目、项目内顺序、网页显示时间、对话链接；正文按
`## 第 N 条可见消息` 分节，节内 `### 用户` / `### AI` 区分角色。
**这个角色区分是语义关键**：「用户」是本人表达，「AI」是外部内容。

## 什么算一条原子笔记

- **一条 = 一个想法**。一份素材通常出 1~8 条；全程没有个人表达的素材出 0 条（在报告里说明）
- 标题 = 一句话主张（10~20 字），正文 1~4 句（中位约 60 字，别超 150 字）
- 第一人称，保留「我」的口吻和语气

## 提炼红线

1. **只提炼用户本人的表达。** AI 的观点只有在用户明确表示认可时才能出现，
   且正文必须以「认可了……」开头，让读者知道这是外部观点的认领。
2. **方括号标注的不确定段，内容一个字都不能进产物**——也不要改写着用，整段绕开。
3. **书面化改写，但不虚构**：口语顺成书面语；具体数字、金额、事实原样保留；
   模糊的感受保持模糊（"非常模糊的感觉"就写"非常模糊的感觉"），不加分析、
   不下结论、不发明因果。
4. 原话本身已经凝练时可以保留原句，但**连续照抄别超过一两句**——校验器把连抄
   120 字判为错误（那是倾倒不是提炼）。
5. 产物里不许有：方括号（`[]`『【】』都不行）、链接、图片语法。
6. `dated` 从素材头部取（voice = 录音日期，chat = 网页显示时间里的日期）。
   **取不到就跳过该素材并在报告里说明——不要猜。**
7. `suggest` 0~2 个，只能用这个词表：**日常、想法、私密、价值观、童年、可分享**。
   拿不准就留空 `[]`。（词表 = 用户已有标签，以用户当面给你的最新版为准。）

## 输出格式（逐字段照抄模板）

```markdown
---
source: 语音备忘录/2026-W27/raw/01-北京路.md
kind: voice
dated: 2026-07-06
suggest: [私密, 价值观]
---

## 一句话标题

正文。
```

- `source`：相对 `原始/` 的路径（它是幂等判重的锚，一个字都不能错）
- `kind`：`voice` | `chat`，必须与 source 的目录一致
- 多条笔记首尾相接写进同一个文件
- 正文里**不要出现独占一行的 `---`**（会撞散记录流的结构）

## 写完必须自查

在仓库目录（`/Users/outsider/Desktop/see me`）下跑：

```
node tools/import/import.mjs check ~/通用空间/潜心/库/<你写的文件>.md
```

修到 **0 错误**为止；每条警告人眼确认后在报告里说明。校验器会查：字段完整、
方括号残留、不确定段混入、成段照抄、链接、词表、条目重复、素材覆盖缺口。

## 最后交一份报告

素材数（含跳过的及原因）／笔记数／每条警告的确认结论／你拿不准的地方。
